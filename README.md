# Aora App

Aora App is a React Native project built with Expo, designed for seamless cross-platform experiences on iOS, Android, and web. The app leverages modern tools and libraries to deliver a dynamic and responsive user interface.

---

## ✨ Features

- **Expo Router**: For intuitive navigation.
- **NativeWind**: Tailwind CSS in React Native for rapid styling.
- **React Navigation**: Smooth and customizable navigation.
- **Media Handling**: Video and document picker support with `expo-video` and `expo-document-picker`.
- **Animations**: Rich animations using `react-native-animatable` and `react-native-reanimated`.
- **Cross-Platform**: Built to run on iOS, Android, and web using `expo`.

## <a name="quick-start">🤸 Quick Start</a>

Follow these steps to set up the project locally.

### **Prerequisites**

Make sure you have the following installed:

- [Node.js](https://nodejs.org/en/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)

### **Cloning the Repository**

```bash
git clone https://github.com/DmytroLysachenko/aora-app.git
cd aora-app
```

### **Installation**

Install dependencies:

```bash
npm install
```

### **Running the Project**

- To start the development server:

```bash
npm run start
```

- For Android:

```bash
npm run android
```

- For iOS:

```bash
npm run ios
```

- For Web:

```bash
npm run web
```

## <a name="scripts">📜 Available Scripts</a>

- `npm run start`: Starts the development server.
